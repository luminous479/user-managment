# User Management System

A simple User Management System built with Go to practice structs, methods, interfaces, pointers, slices, CRUD operations, and error handling.

## Features

- Create users
- Get user by ID
- List users
- Update users
- Delete users
- Input validation
- Error handling
- Sequential ID generation
